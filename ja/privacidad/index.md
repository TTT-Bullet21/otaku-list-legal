## 2. 収集する情報

### 2.1 お客様が直接提供する情報
- **MyAnimeListアカウント（任意）：** MALアカウントを連携する場合、MyAnimeList Co., Ltd.の認証プロセス（OAuth）で許可した権限に従い、あなたのユーザー名およびアニメ・マンガリストにアクセスします。
- **コメントおよび不具合報告：** 本アプリのフィードバック機能を通じて送信されたテキスト。
- **年齢層：** 初回オンボーディング時に入力される年齢確認情報。

### 2.2 自動的に収集される情報
- **利用データ（Firebase Analytics）：** アプリ内での操作イベント（例：カードのスワイプ、ボタンのタップ、利用時間、「あなたの思い出」などのセクションの開閉）。
- **デバイス識別子：** Firebaseによって生成される匿名のインストール識別子、デバイスの機種、OS、およびおおよその国（正確なGPS位置情報ではなく、IPアドレスに基づく）。
- **広告識別子：** Androidデバイスの広告ID。パーソナライズ広告を含む広告を表示するために、当方の広告ネットワーク（Google AdMobおよびAppLovin MAX）が使用します（同意した場合）。
- **Google Signalsのデータ（有効化されている場合）：** デバイスでGoogleアカウントにサインインし、Googleへの同意を行っている場合、この情報がGoogleが既に保有している一般的な興味関心や人口統計データと関連付けられることがあります。この機能の利用にあたり、本アプリ内でGoogleにサインインする必要はありません。

### 2.3 デバイスにローカル保存される情報
- **オフライン同期キュー：** インターネット接続がない状態でアニメ・マンガリストに加えた変更（例：完了としてマークする）は、接続が回復してMyAnimeListと同期されるまで、デバイスの内部ストレージにプライベートに保存されます。
- **同意設定：** 広告に関する同意バナー（GDPR/CCPA）でのあなたの選択は、その選択を記憶するためにローカルに保存されます。

## 3. 情報の共有先

当方は、あなたの個人情報を販売することはありません。本アプリの機能に必要な範囲内でのみ、以下の提供者と情報を共有します。

| 提供者 | 目的 | 共有される情報 |
|---|---|---|
| **MyAnimeList Co., Ltd.** | アニメ・マンガリストの表示および同期 | MALユーザー名、リストへの変更（アカウント連携時） |
| **Google（Firebase Analytics）** | アプリの利用統計 | 操作イベント、匿名のデバイス識別子 |
| **Google（Google Signals、任意）** | 高度な統計および広告 | 同意した場合のGoogleアカウントに関連する興味関心・人口統計データ |
| **Google AdMob / AppLovin MAX** | アプリ内広告の表示 | 広告ID、デバイスの技術情報 |
| **Google Gemini（AI）** | コンテンツの自動翻訳 | MALのあらすじ・説明文のテキスト（個人情報は送信されません） |
| **GitHub（当方の中継サーバー経由）** | コメントおよび不具合報告の管理 | コメント・報告のテキスト内容 |
| **Ko-fi / PayPal / Stripe**（寄付を行った場合） | 任意の寄付の決済処理 | 決済情報はこれらのプラットフォームが完全に管理し、当方はカード情報にアクセスしません |

## 4. 法的根拠および同意

- 欧州連合、英国、および類似の規制（GDPR）がある地域のユーザーについては、パーソナライズ広告およびGoogle Signalsによるデータ関連付けを有効にする前に、同意確認メッセージ（Googleのユーザーメッセージングプラットフォーム、UMP）を通じて明示的な同意を求めます。
- 同意は、アプリ内の**設定 > プライバシーとデータ**からいつでも撤回・変更することができます。
- 16歳未満のユーザーについては、特定のデータ収集機能およびパーソナライズ広告がデフォルトで無効化されます（第7条参照）。

## 5. データの保存期間

- **アナリティクスデータ：** Firebase Analyticsの標準設定に従い保存されます（プロジェクト設定によりますが、一般的に最大14か月）。
- **フィードバックのコメント・報告：** 当方の内部管理リポジトリに無期限に保存されます。アーカイブする場合、またはお客様から削除の申し出があった場合を除きます（第6条参照）。
- **オフライン同期データ：** MyAnimeListとの同期が成功した時点で、デバイスから自動的に削除されます。
- **MALアカウントの連携：** 連携を維持している間保存され、いつでも取り消すことができます。

## 6. お客様の権利

お客様の所在地域（例：EU/英国のGDPR、カリフォルニア州のCCPAなど）により、以下の権利を有する場合があります：

- 保有する情報への**アクセス**権
- 不正確な情報の**訂正**を求める権利
- 情報の**削除**を求める権利（「忘れられる権利」）
- パーソナライズ広告のための情報処理に**異議を唱える**権利
- **情報の共有または販売を行わないよう求める**権利（カリフォルニア州等で適用）

## 7. 未成年者について

- 本アプリの利用には**16歳以上**である必要があります（利用規約第2条参照）。
- オンボーディング時に未成年であると識別された場合、パーソナライズ広告およびGoogle Signalsによるデータ関連付けは自動的に無効化されます。
- 当方は、13歳未満の子供の情報を意図的に収集することはありません。適切な保護者の同意なしに13歳未満の子供の情報を収集したと判断する理由がある場合、当該情報を削除するための措置を講じます。

## 8. 国際的なデータ移転

当方はGoogle、MyAnimeList、GitHub、AppLovinなどの提供者を利用しているため、お客様の情報は、米国を含む、お客様の居住国以外に所在するサーバーに移転され、処理される場合があります。これらの移転は、各提供者が実施しているデータ保護の仕組み（該当する場合、EU標準契約条項など）に基づいて行われます。

## 9. データセキュリティ

- MyAnimeListリストへのアクセス（連携している場合）はOAuth認証トークンによって管理されており、当方はMALのパスワードを保存することはありません。
- デバイスにローカル保存される機密性の高いデータ（セッショントークンなど）は、暗号化された状態で保存されます。
- 当方の中継サーバー（Firebase Cloud Functions）は、フィードバックシステムで使用されるトークンなどの第三者の認証情報を、アプリのコード内に露出させることなく安全に管理します。
